# CampusConnect

## Technologies

- React.js
- MaterialUI
- Node.js
- Express.js
- MongoDB
- JWT

## Overview

CampusConnect is a college-focused platform that supports mentorship, academic material sharing, and college event tracking.

## Features and Contributions

- Designed a structured mentorship module.

- Enabled junior students to connect with senior mentors based on shared technical interests.

- Integrated Cloudinary for PDF storage and retrieval.

- Enabled seamless sharing and organization of academic study materials.

- Implemented an interactive calendar system for tracking college events.

- Added automated date-wise notifications for college events.
